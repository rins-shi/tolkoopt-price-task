# tolkoopt-price-task

Расчёт рекомендуемой цены по предложениям конкурентов.

Нужен Python 3.10 или новее. Сторонние пакеты ставить не нужно: хватает стандартной библиотеки. `starter.py` и `test_starter.py` должны лежать в одной папке. Команды ниже запускать из неё.

## Пример

```bash
python starter.py
```

Показывает пример расчёта. Ожидаемый результат: цена 4728.00 и решение APPLY.

## Тесты

```bash
python -m unittest test_starter.py
```

Запускает проверки: обычный расчёт, сбой источника, пустой отбор, округление вниз и граница 30%.

Если команда `python` не находится, на Windows её можно заменить на `py`.
